# homebrew-tap

Homebrew formulae for [@claytono](https://github.com/claytono) projects.

## Install

```sh
brew install claytono/tap/go-unifi-mcp
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [go-unifi-mcp](https://github.com/claytono/go-unifi-mcp) | MCP server for UniFi Network Controller |

Formulae are automatically updated on each release via
[GoReleaser](https://goreleaser.com/).
